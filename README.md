Skip Rocks for Brainrots

No longer maintained.

Skip Rocks for Brainrots is a Roblox game where players skip rocks to earn cool rewards like Brainrots, collectible meme characters that players can unlock and show off.


About the game

Players skip rocks across the water, and the better the skip, the better the reward. Rewards include Brainrots that players collect.

The game grew a community of 2,000+ members.
