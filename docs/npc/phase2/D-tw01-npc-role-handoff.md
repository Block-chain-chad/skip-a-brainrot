# D — TW-01 NPC Role Handoff (Skipper's Cove)

**From:** NPC-01 · **To:** TW-01 (Trading World rework) · 2026-09-19
**Scope:** recommended roles only. **TW-01 owns placement, district layout, counts, prompt positions and social spaces.** NPC-01 owns how each character looks, is rigged, dressed, propped and animated, and delivers finished bodies to `ServerStorage.NpcStaging.Trading`. Nothing is placed by NPC-01.

**Where this comes from.** The Cove today has **no NPC cast** — player booths (`TradingCenter.Booths.Booth1–12`), the trade gazebo/`TradeZone`, three surfboard boards, the coral `IndexGate` (reserved "for later prompt wiring"), three reward chests, the Eternal Skip, six giant brainrot statues, and the wave-portal arrival at `TRADE_POS` `[code/doc: skippers-cove-design, cove-rebuild-woah, TeleportService]`. Palette: sand (238,214,166) · coral (255,116,96) · turquoise (54,224,214) · gold (255,196,64) · shell white · driftwood — "chunky low-poly, SmoothPlastic + sparing Neon" `[doc]`.

**Cove style rule (NPC-01 standard §27):** rich, upright, chin-up people; `trader`/`noble` families; **one** gem accent per character; gold as trim never base; Merchant pack at 1.15× speed; standard scale (the statues are the giants); no Highlights, ≤ 1 Neon sliver per NPC.

## D2. What NPC-01 needs back from TW-01

1. Confirmed role list and **counts** (especially Background Collectors: 3–6 and how many variants).
2. **Prompt names** for the dialogue roles — suggestion, if none exists: `TwAppraiserPrompt`, `TwGreeterPrompt`, `TwGatePrompt`, `TwHarbourPrompt`, each inside a `PromptPart` on the character's root model (the `StallPrompt` convention).
3. Whether any role hooks into a system (booth occupancy, `PriceIndex`, the Index gate action) so lines can be written against real data, and who owns that config (`TradingNpcConfig`, modelled on `GardensNpcConfig`).
4. Approximate **sight lines** (where each NPC faces — the portrait camera uses the root's `LookVector` `[code: MerchantDialog]`).
5. Whether the Cove's palette gets a **night/red-night** variant (affects only colours of overlays, not bodies).

## D3. What TW-01 gets from NPC-01

Finished bodies in `ServerStorage.NpcStaging.Trading`, each: SR-Rig (kit C), tagged `NpcBody` with `NpcWorld = "Trading"`, family/colours/props per D1, `NpcBudget` PASS, and a `PromptPart` placeholder at the front of the character (TW-01 moves the model, keeps the part). Placement, orientation and district assignment are entirely TW-01's; NPC-01 will re-check portraits and prompt readability after placement, on request.
